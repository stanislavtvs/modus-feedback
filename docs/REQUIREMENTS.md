ТЗ разрешает команде определить объём MVP. Опросы, NPS и реальные интеграции не включены. Приватный репозиторий опубликован; доступ жюри выдаёт владелец. Формальная промышленная приёмка и защита перед жюри не проводились.

Помощник Gemma через Ollama — дополнительная функция пользователя: генерация черновика, объяснение обращения, вопросы и черновик ответа; применение выполняет человек. Подробный результат чистого запуска и репетиции — в RELEASE_CHECK.md.

## Дополнительные функции по запросу пользователя

Эти функции добавлены для развития MVP; они не выдаются за отдельные обязательные пункты исходного ТЗ или гарантию дополнительных баллов жюри.

| Функция | Реализация | Проверка |
|---|---|---|
| ИИ-радар повторяющихся проблем | Gemma предлагает семантические группы из разрешённых обращений; руководитель редактирует, подтверждает или отклоняет связь | Реальная модель + тесты границ доступа и отклонения некорректного ответа |
| Контроль забытых обращений | Отдельный Docker-процесс раз в минуту, первый ответ/нет обновлений/просрочка, внутрисистемное напоминание и эскалация администратору | Тесты времени, повторного запуска, уточнений, завершения и персональности |
| Проверка результата автором | Одна оценка на версию решения; «Проблема осталась» с пояснением возвращает в работу, обновляет срок, уведомляет ответственного | Полный сценарий и защита от устаревших/чужих/повторных оценок |
| Витрина улучшений | Только подтверждённое решение и явное одобрение руководителя; отдельный текст и аудитория; автоматическое снятие при изменении результата | Черновик, публикация, аудитория подразделение/компания, отсутствие доступа к исходной карточке, повторное открытие |

| Последующее дополнение | Реализация |
|---|---|
| Пульс подразделений | Сводка по разрешённым обращениям, актуальные подтверждения автора, возвраты, активные напоминания; без рейтингов сотрудников |
| Паспорт системной проблемы | Из подтверждённой темы: цель, владелец с прежними правами, план, срок, состояние, результат и история; без автоматического закрытия обращений |
| Прозрачная передача в ИИ | Обязательный предварительный просмотр всех трёх режимов, эвристическая подсветка/маскирование, подпись отпечатка и повторная проверка доступа |
| Режим демонстрации | Отдельные Compose-проект/секреты/тома/cookies, маркировка учебных данных, маршрут показа и защищённая команда подготовки |

Паспорт дополнен чек-листом действий с отдельными ответственными, сроками, прогрессом и историей. Итоговая проверка и оставшиеся ограничения — FINAL_REVIEW.md.
