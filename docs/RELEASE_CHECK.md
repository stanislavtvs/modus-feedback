# Проверка комплекта для сдачи

Проверка чистой установки выполняется в отдельной копии Git-репозитория, отдельном проекте Docker Compose, с новым `.env` и отдельными томами PostgreSQL/вложений. Рабочая установка на порту 8018 не используется для этих проверок.

Итоговые команды, результат и идентификатор проверенного коммита будут зафиксированы после завершения проверки.
